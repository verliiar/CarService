# CarService

CarService — backend-сервис для автоматизации работы автосалона, разработанный на C# и ASP.NET Core (.NET 10).

Приложение объединяет каталог автомобилей, конфигуратор комплектаций, оформление заказов и бронирование тест-драйвов. Реализованы управление пользователями, разграничение прав доступа и проверка бизнес-ограничений.

## Технологии

* C# / .NET 10 — основной язык и платформа разработки.
* ASP.NET Core Web API — реализация REST API.
* PostgreSQL — хранение данных.
* Entity Framework Core — работа с базой данных и миграциями.
* ASP.NET Core Identity / JWT — аутентификация и авторизация.
* Docker Compose — запуск приложения и PostgreSQL.
* xUnit / Testcontainers — модульное и интеграционное тестирование.

## Возможности

* Управление каталогом автомобилей и фильтрация по характеристикам.
* Подбор индивидуальных комплектаций с проверкой совместимости компонентов.
* Автоматический расчёт стоимости автомобиля.
* Оформление заказов на автомобили из наличия и под заказ.
* Управление статусами заказов.
* Бронирование тест-драйвов с проверкой доступности автомобилей.
* Регистрация и авторизация пользователей.
* Разграничение доступа между клиентами, менеджерами и администраторами.
* Контроль конкурентных изменений и целостности данных.

## Архитектура

Проект построен на основе Clean Architecture с разделением на четыре слоя:

* **Domain** — доменные сущности и бизнес-правила.
* **Application** — бизнес-сценарии и контракты.
* **Infrastructure** — взаимодействие с базой данных, Identity и миграции.
* **API** — REST-контроллеры, валидация и авторизация.

## Локальный запуск

Для запуска необходимы **Docker Compose**.

Создайте файл `.env` в корне проекта и укажите необходимые переменные окружения:

```env
POSTGRES_PASSWORD=your_postgres_password
JWT_SIGNING_KEY=your_secret_key_at_least_32_characters
BOOTSTRAP_ADMIN_EMAIL=admin@example.test
BOOTSTRAP_ADMIN_PASSWORD=your_secure_admin_password
API_PORT=8080
POSTGRES_PORT=5432
```

Запустите приложение:

```bash
docker compose up --build -d --wait
```

Миграции базы данных применяются автоматически.

После запуска API доступен по адресу `http://localhost:8080`, спецификация OpenAPI — `http://localhost:8080/openapi/v1.json`.

## Тестирование

Для запуска тестов необходимы **.NET 10 SDK** и Docker.

```bash
dotnet test
```

Проект содержит 202 автоматизированных теста: 142 модульных и 60 интеграционных.
